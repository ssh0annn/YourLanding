# YourLanding
Landing Page para mi negocio yourLading

## 🚀 YourLanding: Landing Pages Profesionales de Alto Impacto

¡Bienvenido al repositorio de **YourLanding**, una landing page diseñada para atraer empresas y pequeños negocios que buscan soluciones de conversión efectivas a través de landing pages!

Este proyecto es una demostración de una landing page rápida, ligera y totalmente *responsive*, construida exclusivamente con tecnologías web fundamentales (HTML, CSS y un toque de JavaScript) para garantizar la máxima compatibilidad y velocidad.

---

### ✨ Características Principales

* **Diseño Limpio y Profesional:** Estilo moderno enfocado en la conversión.
* **100% Responsive:** Adaptación perfecta a móviles, tabletas y ordenadores.
* **Puro Código:** Construido sin frameworks (como Tailwind o Bootstrap), usando **CSS puro** para un código limpio y ligero.
* **Contacto Directo (Mailto):** Implementación de una acción directa que redirige al cliente a su email con una plantilla de solicitud pre-rellena.

### 📂 Estructura del Proyecto

El proyecto está autocontenido en un solo archivo, lo que lo hace ideal para despliegues rápidos y simples.

### ⚙️ Instalación y Uso

Dado que el proyecto está en un único archivo estático, la puesta en marcha es extremadamente sencilla:

1.  **Descarga el archivo:** Guarda el código proporcionado como `index.html`.
2.  **Sube a tu servidor:** Sube el archivo `index.html` a la carpeta raíz de tu alojamiento web (ej. `public_html` o `www`).
3.  **Accede:** Abre tu navegador y navega a tu dominio (`https://tudominio.com/`).

### 📝 Configuración del Contacto (Mailto)

El enlace de contacto ha sido configurado para que, al hacer clic, se abra el cliente de email del usuario con un asunto y un cuerpo predefinidos.

⚠️ **IMPORTANTE:** Debes reemplazar el placeholder por tu dirección de correo electrónico real en el archivo `index.html`.
